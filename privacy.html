プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-01

1. 対象 / Scope

本ポリシーは、個人用ツール「Channel Uploader」（以下「本ツール」）が Google アカウントのデータをどう扱うかを定めます。本ツールの利用者は運営者本人のみです。

This policy describes how Channel Uploader ("the tool") handles Google account data. The only user of the tool is its operator.

2. 取得する情報 / Data accessed

本ツールは、YouTube Data API（スコープ: https://www.googleapis.com/auth/youtube）を通じて、運営者自身の YouTube チャンネルの情報（チャンネル名・ID、アップロードした動画の情報、再生リスト）にアクセスします。

The tool accesses the operator's own YouTube channel data (channel name and ID, uploaded video metadata, playlists) through the YouTube Data API.

3. 利用目的 / How data is used

取得した情報は、運営者のチャンネルへの動画・タイトル・概要欄・字幕・サムネイルの登録と、投稿先チャンネルの確認にのみ使います。

Data is used only to upload videos, titles, descriptions, captions and thumbnails to the operator's channels and to confirm the destination channel.

4. 保存と共有 / Storage and sharing

認証情報（リフレッシュトークン）は運営者の PC 内にのみ保存され、外部のサーバーには保存しません。取得した情報を第三者に提供・販売することはありません。

Credentials (refresh tokens) are stored only on the operator's own computer and never on external servers. No data is sold or shared with third parties.

5. Google API サービスのユーザーデータに関するポリシー / Google API Services User Data Policy

本ツールによる Google API から受け取った情報の使用は、限定的使用の要件を含む Google API Services User Data Policy に準拠します。

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. アクセスの取り消し / Revoking access

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールのアクセスを取り消せます。

Access can be revoked at any time from the "Third-party apps & services" page of the Google Account.

7. YouTube 利用規約 / YouTube Terms

本ツールは YouTube API サービスを使用しています。YouTube 利用規約、Google プライバシーポリシーもご確認ください。

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
