Channel Uploader

Channel Uploader は、運営者が自分の YouTube チャンネルに、自ら制作した歴史解説動画をアップロードするための個人用ツールです。一般の利用者向けのサービスではありません。

Channel Uploader is a personal tool the operator uses to upload their own history documentary videos to their own YouTube channels. It is not offered to the public.

機能 / What it does

  • YouTube Data API を使い、運営者のチャンネルへ動画・タイトル・概要欄・字幕・サムネイルを登録します。
  • Uses the YouTube Data API to upload videos, titles, descriptions, captions and thumbnails to the operator's own channels.
